# Portfolio

Portfolio personnel réalisé dans le cadre du cours React et Node.js.

## Objectif

Créer un site web professionnel pour présenter le profil, les compétences, le parcours et les projets.

## Technologies prévues

- Frontend : React et Vite
- Backend : Node.js et Express
- Données : fichiers JSON
- Navigation : React Router

## Structure prévue

- `frontend/` : application React
- `backend/` : API Express et données JSON
- `docs/` : documentation du projet

## Installation

Les instructions d'installation seront ajoutées au fur et à mesure de la mise en place du projet.
