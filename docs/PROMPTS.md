# Journal des prompts et vérifications

## Principes
- Ne pas inventer de coordonnées, dates, expériences, projets, résultats ou niveaux de compétence.
- Garder le contenu personnel dans les fichiers JSON du backend.
- Comprendre et vérifier chaque composant généré par IA.
- Ne jamais committer de fichier .env ou de secret.

## Prompt d'architecture
« Construis un portfolio full-stack pour un étudiant de M2 Manager en ingénierie informatique, parcours Smart & Green Building. Utilise React + Vite, Node.js + Express, React Router et des fichiers JSON versionnés. Respecte les routes /api/profil, /api/projets, /api/projets?tag=IoT, /api/projets/:slug, /api/competences et /api/parcours. Ne crée pas de fausses informations personnelles ni de faux projets. »
